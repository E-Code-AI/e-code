Problème #7: Path Traversal possible
Fichier: /home/user/e-code/server/agent/tool-executor.ts (ligne 91-100)

  return path.normalize(filePath); // ❌ Unicode peut bypass
}

Impact: Accès à des fichiers hors du sandbox
Solution:

  const normalizedPath = path.resolve(baseDir, filePath);
  if (!normalizedPath.startsWith(path.resolve(baseDir))) {
    throw new Error('Path traversal detected');
  }
  return normalizedPath;
}
