2.2 STATISTIQUES DE CACHE PLACEHOLDER
Fichier: server/services/ai-optimization/plan-cache.service.ts (lignes 86-106)

Problème:

async getStats(): Promise<...> {
  return {
    totalCached: 0,    // Toujours 0!
    totalHits: 0,
    avgTokensSaved: 0,
  };
}

Solution:

async getStats(): Promise<CacheStats> {
  const keys = await this.redis.keys('plan-cache:*');
  const hits = await this.redis.get('plan-cache:hits') || 0;
  const tokensSaved = await this.redis.get('plan-cache:tokens-saved') || 0;
  
  return {
    totalCached: keys.length,
    totalHits: Number(hits),
    avgTokensSaved: keys.length ? Number(tokensSaved) / keys.length : 0,
  };
}
