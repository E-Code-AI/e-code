## 📝 Notes Importantes

### Architecture Actuelle
```
┌─────────────────────────────────────────────────────────┐
│                     E-Code Platform                      │
├─────────────────────────────────────────────────────────┤
│                                                           │
│  ┌───────────────┐  ┌───────────────┐  ┌──────────────┐ │
│  │  Frontend      │  │  Backend       │  │  Supabase    │ │
│  │  React + TS    │←→│  Edge Function │←→│  Database    │ │
│  │  Tailwind      │  │  Hono Server   │  │  Storage     │ │
│  │  shadcn/ui     │  │  /server/      │  │  Auth        │ │
│  └───────────────┘  └───────────────┘  └──────────────┘ │
│                                                           │
│  ┌───────────────────────────────────────────────────┐  │
│  │            Agent AI (Cœur du Système)             │  │
│  │  • Panneau gauche dans l'IDE                      │  │
│  │  • Chat interface                                 │  │
│  │  • Actions automatiques (create, modify, debug)   │  │
│  │  • Multi-modèles (Claude, GPT-4, etc.)           │  │
│  │  • Streaming responses                            │  │
│  └───────────────────────────────────────────────────┘  │
│                                                           │
└─────────────────────────────────────────────────────────┘
```

### Différence Clé vs Replit
**E-Code = Replit + Agent AI intégré comme cœur du workflow**
- L'Agent AI n'est pas juste un assistant, c'est le PRIMARY INTERFACE
- L'agent peut créer, modifier, debugger tout le projet
- Workflow: User → Agent → Code (au lieu de User → Code)

### Stack Technique
```json
{
  "frontend": "React 18 + TypeScript + Vite",
  "styling": "Tailwind CSS v4.0 + shadcn/ui",
  "backend": "Supabase Edge Functions (Deno) + Hono",
  "database": "Supabase Postgres + KV Store",
  "storage": "Supabase Storage",
  "auth": "Supabase Auth (OAuth 2.0, OIDC, SAML 2.0)",
  "ai": "Multi-provider (OpenAI, Anthropic, Google)",
  "monitoring": "Sentry",
  "payments": "Stripe",
  "testing": "Vitest + React Testing Library"
}
```
