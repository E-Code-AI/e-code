## 💾 AUTO-SAVE SYSTEM

**Timer Ref**: `autoSaveTimerRef` (ligne 181)

**Délai**: 2 secondes d'inactivité (ligne 511)

**Fonction**: `saveFileToBackend(tabId, content)` (ligne 515)

**Flow**:
```
1. User types in editor
   ↓
2. onChange triggered
   ↓
3. handleFileContentChange() called (ligne 496)
   ↓
4. Update tab content in state
   ↓
5. Clear existing timer
   ↓
6. Set new timer (2 seconds)
   ↓
7. If no typing for 2s → saveFileToBackend()
   ↓
8. PUT /projects/:projectId/files
   ↓
9. Update file tree in memory
```
