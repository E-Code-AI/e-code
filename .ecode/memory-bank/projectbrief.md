# Project Brief

## Overview
E-Code is an AI-assisted web-based IDE for rapid prototyping, education, and enterprise use. It enables autonomous workspace generation from natural language prompts, offering live previews and streaming progress. The platform supports multi-provider AI model selection, real-time collaboration, and robust security.

## Core Requirements
- AI-powered code generation with multi-provider support (OpenAI, Anthropic, Gemini, xAI, Moonshot)
- Real-time collaboration with Yjs and WebSocket
- Monaco code editor with syntax highlighting for 29+ languages
- Integrated terminal with PTY support
- Checkpoint and rollback system for code versioning
- Mobile-first responsive design with Replit-style UI
- Fortune 500-level reliability and performance

## Project Goals
1. Streamline coding workflow with AI assistance
2. Provide enterprise-grade security and reliability
3. Enable collaborative coding in real-time
4. Support rapid prototyping from natural language

## Scope
- Full-stack TypeScript application (React + Express)
- PostgreSQL database with Drizzle ORM
- Multi-tenant architecture with tier-based rate limiting
- Kubernetes-ready deployment with health probes
