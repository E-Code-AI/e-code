## 7.1 CRITIQUES (5)

 

### PROBLÈME A-C1: Command injection dans tool-executor

**Fichier:** `/server/agent/tool-executor.ts` lignes 255-287

**Code actuel:**

```typescript

execAsync(params.command, { cwd: this.projectRoot, timeout });

```

**Solution:**

```typescript

import { spawn } from 'child_process';

const args = parseCommand(params.command); // Parse safely

spawn(args[0], args.slice(1), { cwd: this.projectRoot, shell: false });

```

### PROBLÈME A-C2: Path traversal dans createFile

**Fichier:** `/server/agent/tool-executor.ts` lignes 133-154

**Code actuel:**

```typescript

const fullPath = path.join(this.projectRoot, params.path);

// Pas de validation! ../../etc/passwd possible

```

**Solution:**

```typescript

const fullPath = path.join(this.projectRoot, params.path);

if (!fullPath.startsWith(this.projectRoot)) {

  throw new Error('Path traversal detected');

}

```
