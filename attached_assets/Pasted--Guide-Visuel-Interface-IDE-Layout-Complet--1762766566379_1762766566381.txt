## 🎨 Composants Détaillés

### **1️⃣ Top Navigation Bar**

```
┌─────────────────────────────────────────────────────────────────────────┐
│  ┌─────┐                                                                │
│  │ E-C │  my-project     [Preview] [App.tsx] [index.tsx] [+]    [▶ Run]│

│   Logo    Project Name      Tab1     Tab2      Tab3    Add Tab  Run Btn│
```

**Elements:**
- **Logo**: E-Code icon (Code icon)
- **Project Name**: "my-project" (editable in real version)
- **Tabs**: Horizontal tabs for open files/tools
- **Add Button**: Open new tab menu
- **Run Button**: Green = Run, Red = Stop
- **Settings**: User menu dropdown

### **4️⃣ File Explorer Panel** (Droite)

```
┌────────────────────┐
│  📁 Files      [X] │  ← Header
├────────────────────┤
│  ▼ my-project      │  ← Root folder (expanded)
│    ▼ src           │  ← Subfolder (expanded)

│  [+ Folder]        │  ← Create folder button
```

**Icons:**
- **▼** = Folder expanded
- **▶** = Folder collapsed
- **📁** = Folder icon
- **📄** = File icon
- **Highlight** = Selected item

## 🎯 Interactions Flow

### **Ouvrir un fichier**
```
User clicks "App.tsx"
    ↓
File Explorer selects it
    ↓
New tab created/focused
    ↓
Editor loads file content
    ↓
Toast: "Opened App.tsx"
```

### **Modifier du code (IDEPage uniquement)**
```
User types in editor
    ↓
onChange event fires
    ↓
Update tab content
    ↓
Start 2-second timer
    ↓
Timer expires
    ↓
Save to backend
    ↓
Update file tree
```

### **Run/Stop projet**
```
User clicks "Run" button
    ↓
Button turns red
    ↓
Status changes to "🟢 Running"
    ↓
Console shows output
    ↓
Toast: "Project started"
```

### **Chat avec AI**
```
User types message
    ↓
Press Enter or click Send
    ↓
Message added to chat
    ↓
AI response appears
    ↓
(In real version: API call to OpenAI)
```

## 🎨 Animations

### **Panel Resize**
```
User drags ResizableHandle
    ↓
Smooth transition (150ms)
    ↓
Panels resize proportionally
    ↓
Content reflows
```

### **Tab Switch**
```
User clicks tab
    ↓
Tab background changes (accent color)
    ↓
Fade out current content (100ms)
    ↓
Fade in new content (100ms)
```

### **File Select**
```
User clicks file
    ↓
Highlight background (accent color)
    ↓
Create/switch to tab (200ms slide)
    ↓
Toast notification
```

### **Toast Notifications**
```
Action triggered
    ↓
Toast slides in from top-right (300ms)
    ↓
Display for 3 seconds
    ↓
Slide out (300ms)
```

```typescript
showFileExplorer→ boolean

```

### **State Flow**
```
User Action
    ↓
Event Handler
    ↓
setState()
    ↓
React Re-render
    ↓
UI Updates
    ↓
(Optional) Toast Feedback
```
