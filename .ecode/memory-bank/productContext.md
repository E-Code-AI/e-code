# Product Context

## Problem Statement
Developers need a modern, AI-powered IDE that works anywhere without local setup. Existing solutions lack seamless AI integration, real-time collaboration, or enterprise-grade reliability.

## Target Users
1. **Students & Educators** - Learning to code with AI assistance
2. **Rapid Prototypers** - Building MVPs quickly from natural language
3. **Remote Teams** - Collaborating on code in real-time
4. **Enterprise Developers** - Requiring security, reliability, and compliance

## User Experience Goals
- Instant access: No installation, works in any browser
- AI-first: Natural language to working code
- Mobile-friendly: Full IDE experience on tablet and phone
- Fast: Sub-second perceived load times, instant feedback
- Reliable: Fortune 500-grade uptime and performance

## How It Should Work
1. User describes what they want to build in natural language
2. AI generates project scaffold, code, and configurations
3. Live preview shows results immediately
4. User refines with AI chat or direct code editing
5. One-click deployment when ready
