## 1.1 CRITIQUES (3)

 

### PROBLÈME B-C1: SendGrid API Key vide par défaut

**Fichier:** `/server/utils/sendgrid-email-service.ts` ligne 11

**Code actuel:**

```typescript

const SENDGRID_API_KEY = process.env.SENDGRID_API_KEY || '';

```

**Impact:** Bypass de la vérification email, comptes non vérifiés peuvent s'inscrire

**Solution:**

```typescript

const SENDGRID_API_KEY = process.env.SENDGRID_API_KEY;

if (!SENDGRID_API_KEY) {

  throw new Error('SENDGRID_API_KEY is required in production');

}

```

### PROBLÈME B-H15: Streaming endpoint sans error handling

**Fichier:** `/server/routes/chatgpt.router.ts` lignes 184-190

**Code actuel:**

```typescript

for await (const chunk of stream) {

  res.write(chunk); // Pas de try-catch

}

```

**Impact:** Memory leak si erreur pendant streaming

**Solution:**

```typescript

try {

  for await (const chunk of stream) {

    res.write(chunk);

  }

} catch (error) {

  logger.error('Streaming error:', error);

  res.destroy(error);

} finally {

  res.end();

}

```
