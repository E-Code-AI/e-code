# Mobile Assets Required\n\nThe following files are required for mobile app publishing:\n\n## Icons\n- icon.png (1024x1024) - App icon\n- adaptive-icon.png (1024x1024) - Android adaptive icon  \n- splash.png (1284x2778) - Splash screen\n\n## Firebase Configuration\n- google-services.json (Android) - Download from Firebase Console\n- GoogleService-Info.plist (iOS) - Download from Firebase Console\n\n## How to obtain:\n1. Create a Firebase project at https://console.firebase.google.com\n2. Add Android and iOS apps to the project\n3. Download the configuration files\n4. Place them in this directory\n\n## Generate icons:\nUse a tool like https://appicon.co or Expo's asset generator
