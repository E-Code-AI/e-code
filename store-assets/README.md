# Mobile Store Assets

This directory contains App Store and Play Store metadata, privacy disclosures, and deep-link verification files intended for upload to the versioned `ecode-store-assets` Cloud Storage bucket.

Image and video binaries must be produced from the final native builds because App Store Connect and Play Console reject screenshots that do not match current device UI. The required slots are iPhone 6.7, 6.5, 5.5, iPad 12.9, iPad 11, Android phone, Android tablet, and 15-30 second previews for iOS and Android.
