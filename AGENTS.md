# AGENTS.md

## Cursor Cloud specific instructions

### Services overview

| Service | Port | How to start |
|---------|------|--------------|
| Main platform (Express + Vite) | 5000 | `source .env.local && npm run dev` |
| PostgreSQL (Docker) | 5455 | `./scripts/setup-local-db.sh` (idempotent) |
| Runner microservice (optional) | 8080 | `RUNNER_JWT_SECRET=secret npx tsx runner/index.ts` |

### Key commands (see `package.json` scripts for full list)

- **Lint**: `npm run lint`
- **Typecheck**: `npm run typecheck`
- **Build**: `npm run build`
- **Unit tests**: `npm run test:unit -- --runInBand`
- **Integration tests**: `npm run test:integration -- --runInBand`
- **Backend smoke**: `npm run test:smoke:backend`
- **Dev server**: `source .env.local && npm run dev`

### Non-obvious caveats

1. **Login uses `email` field** — the Passport LocalStrategy uses `usernameField: 'email'`, so POST `/api/login` expects `{ email, password }`, not `{ username, password }`.

2. **Docker required for DB** — `./scripts/setup-local-db.sh` needs a running Docker daemon. It creates a `postgres:16-alpine` container named `e-code-postgres` on port 5455 and writes `DATABASE_URL` to `.env.local`. Always `source .env.local` before running the app or tests that need the DB.

3. **Redis optional in dev** — The app falls back to in-memory session store (`memorystore`) when Redis is not available. Redis is only required in production.

4. **TypeScript errors are pre-existing** — `npm run typecheck` currently reports ~30 errors in `server/routes/git-project.router.ts`, `server/routes/shell.ts`, and a few others. These do not block `npm run build` or `npm run dev` (Vite/esbuild transpiles without type checking).

5. **CSRF disabled in dev** — `.env.example` sets `DISABLE_CSRF=true` for local development. When testing with CSRF enabled, grab the `csrfToken` from the login response and pass it as `X-CSRF-Token` header.

6. **Docker daemon in Cloud Agent VMs** — needs `fuse-overlayfs` storage driver and `iptables-legacy`. Start with `dockerd &>/tmp/dockerd.log &` then wait ~3s before using.

7. **Build output** — `npm run build` produces `dist/index.js` (server bundle) and `dist/public/` (Vite frontend). The dev server (`npm run dev`) uses tsx + Vite dev middleware instead.

8. **`.env` vs `.env.local`** — `.env.local` is auto-generated by `setup-local-db.sh` and contains `DATABASE_URL`. It is loaded with higher priority than `.env`. Never put production credentials in `.env`.
