# PARTIE 4: PROBLÈMES DESKTOP APP (21 issues)

 

## 4.1 CRITIQUES (5)

 

### PROBLÈME D-C1: Icons manquants

**Fichier:** `/desktop/package.json` lignes 99, 111

**Fichiers manquants:**

- `resources/icon.ico` (Windows)

- `resources/icon.icns` (macOS)

- `resources/installer-header.bmp`

- `resources/installer-sidebar.bmp`

 

**Solution:** Générer icons avec:

```bash

# macOS

iconutil -c icns icon.iconset

 

# Windows - utiliser png2ico ou convertisseur en ligne

```

 

---

 

### PROBLÈME D-C2: Code signing désactivé

**Fichier:** `/desktop/package.json` lignes 66, 70, 101

**Code actuel:**

```json

"sign": false,

"notarize": false,

"verifyUpdateCodeSignature": false

```

**Impact:** App rejetée par Gatekeeper (macOS) et SmartScreen (Windows)

**Solution:** Obtenir certificats Apple Developer et Windows Code Signing

 

---

 

### PROBLÈME D-C3: CSP trop permissive

**Fichier:** `/desktop/scripts/prepare-renderer.js` ligne 75

**Code actuel:**

```

'unsafe-eval' 'unsafe-inline'

```

**Impact:** Vulnérabilité XSS et code injection

**Solution:** Retirer unsafe-eval, utiliser nonce-based CSP

 

---

 

### PROBLÈME D-C4: System tray non implémenté

**Fichier:** `/desktop/main.js`

**Impact:** Pas de minimize-to-tray, pas de quick access

**Solution:** Implémenter Tray avec menu contextuel

 

---

 

### PROBLÈME D-C5: Deep linking non implémenté

**Fichier:** `/desktop/main.js`

**Solution:**

```javascript

app.setAsDefaultProtocolClient('ecode');

app.on('open-url', (event, url) => {

  // Handle ecode:// URLs

});

```
